# Video Kiosk Lab Postman Collection

This is a postman collection for video kiosk lab. In the devnet lab, currently we are using link to download from postman collection directly. But this repo gives access to download the postman collection from here, instead from postman. To download this collection in the lab, use this command.

```
wget https://raw.githubusercontent.com/wxsd-sales/video-kiosk-lab/refs/heads/main/collection.json -O collection.json
```
